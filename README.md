# Ardan

Сайт с публичным просмотром видео и закрытой панелью оператора.

## Запуск
1. Установите Node.js.
2. В папке проекта: `npm install`
3. Задайте пароль: `OPERATOR_PASSWORD=ваш_пароль`
4. Запустите: `npm start`
5. Для ссылки другим людям разместите проект на сервере/хостинге с Node.js.

Видео хранятся на сервере в `uploads/`, а список — в `data.json`.
